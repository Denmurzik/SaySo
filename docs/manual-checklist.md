# Ручная проверка SaySo

Что нельзя проверить автоматически — нужен живой голос и реальные окна.

1. Установка из исходников (путь разработчика; для пользователей — установщик, п. 19–20): `powershell -ExecutionPolicy Bypass -File .\build.ps1`, затем `powershell -ExecutionPolicy Bypass -File .\install.ps1` — в трее появился значок микрофона; при первом запуске открылись настройки: окно с заголовком «SaySo» (без «— настройки»), боковое меню («Общие», «Распознавание», «Словарь», «Микрофон», «История», «О программе») всегда раскрыто и не сворачивается.
2. Ключи: «Распознавание» → вставить ключи Gemini и Groq → «Проверить ключи» — обе проверки зелёные.
3. Блокнот: удерживая правый Ctrl, сказать «Ну, э-э, давай встретимся в пятницу, нет, в субботу в три часа дня» — вставилось «Давай встретимся в субботу в 15:00.» (или близко), без «ну» и «э-э».
4. Короткое нажатие правого Ctrl — запись идёт без удержания; повторное нажатие — текст вставлен.
5. Esc во время записи — ничего не вставлено, плашка исчезла.
6. Правый Ctrl + C (копирование) — диктовка не началась/тихо отменилась, копирование сработало.
7. Скопировать в буфер слово «проверка», продиктовать фразу, затем Ctrl+V — вставилось «проверка» (буфер восстановлен); в Win+V диктовки нет.
8. Две диктовки подряд в одно поле — между предложениями есть пробел.
9. Терминал от администратора: без режима администратора — на плашке «Админ-окно: текст в буфере, вставьте Ctrl+V», текст в буфере. Включить «Запускать от имени администратора» (UAC) — диктовка вставляется в админ-терминал.
   - В Планировщике заданий есть задача `SaySo` (триггер — вход в систему), в её свойствах включено «Выполнять с наивысшими правами» (`schtasks /Query /TN SaySo /XML` — в выводе `<RunLevel>HighestAvailable</RunLevel>`).
   - После перезахода запущенный демон — с правами администратора (в Диспетчере задач у процесса SaySo колонка «Повышенные права» = «Да»), но клики по значку в трее и меню по-прежнему работают, а окно настроек (обычный процесс) получает ответы демона: «Применить»/сохранение настроек, «Проверить ключи», история.
   - Повторный запуск `SaySo.exe` (например, ярлыком из меню «Пуск») не создаёт второй демон, а открывает окно настроек.
   - Выключить «Запускать от имени администратора» — задача `SaySo` исчезает из Планировщика, автозапуск возвращается к Run-ключу.
10. Несколько ключей: добавить второй ключ Gemini, первый временно испортить → диктовка проходит через второй ключ без сообщения на плашке (в журнале — «Gemini: ключ №1 — AuthFailed»). Испортить оба → диктовка приходит через Groq, на плашке «Резерв Groq (…)».
11. Микрофон: «Микрофон» → «Проверить микрофон» — полоска реагирует на голос; выбор другого устройства работает. Какой микрофон реально используется, видно по полоске уровня (или говорите в нужный микрофон). Запоминание выбора (нужна гарнитура, USB или Bluetooth):
   - Выбрать гарнитуру → отключить её → диктовка работает через микрофон Windows по умолчанию (без ошибки) → подключить гарнитуру снова → диктовка идёт через гарнитуру без повторного выбора в настройках.
   - То же, но подключить гарнитуру в другой USB-порт (у неё может смениться идентификатор) → гарнитура всё равно подхватывается (по имени).
   - Выбрать встроенный микрофон при подключённой гарнитуре → диктовка идёт через встроенный; после переподключения гарнитуры и перезапуска SaySo выбор остаётся за встроенным.
   - Выбрать «Как в Windows (по умолчанию)» → сменить устройство ввода по умолчанию в Windows → диктовка следует за ним.
12. История: последние диктовки видны, «Копировать» работает; трей → «Вставить последнее» вставляет в последнее окно.
13. Перезагрузка: SaySo стартует сам (Run-ключ или задача Планировщика).
14. Диспетчер задач через минуту простоя: SaySo — единицы–десятки МБ; после закрытия настроек второго процесса SaySo нет.
15. Сон и блокировка: перевести компьютер в сон и разбудить; затем заблокировать (Win+L) и разблокировать — горячая клавиша диктовки после каждого из этих действий снова работает без перезапуска SaySo.
16. Значок в трее: правая кнопка открывает меню («Вставить последнее», «Скопировать последнее», «Настройки…», «Приостановить», «Выход»), каждый пункт работает; двойной клик открывает настройки; одиночный левый клик ничего не показывает, но переустанавливает хук горячей клавиши (если диктовка перестала реагировать — клик по значку возвращает её); «Выход» завершает процесс.
17. Тема Windows: переключить светлую/тёмную тему («Параметры → Персонализация → Цвета») — значок в трее перерисовывается в цвет новой темы без перезапуска.
18. Уровень микрофона: «Микрофон» → «Проверить микрофон» — полоска уровня движется в такт голосу и замирает в тишине; после закрытия проверки индикатор Windows «микрофон используется» гаснет.
19. Установщик, режим «только для меня» (нужен Setup из релиза или `build-installer.ps1`; на ПК не должно быть другой установки SaySo): запустить `SaySo-Setup-X.Y.Z.exe` — SmartScreen предупреждает («Подробнее» → «Выполнить в любом случае»); в мастере по умолчанию выбран «только для меня», запроса UAC нет; язык мастера следует языку Windows; папка по умолчанию `%LOCALAPPDATA%\Programs\SaySo`.
   - После установки: ярлык «SaySo» в меню «Пуск» работает; ярлыка на рабочем столе нет, если не отмечена задача; галочка «Запустить SaySo» запускает демон, значок в трее появился.
   - «Параметры → Приложения → Установленные приложения»: запись SaySo с нужной версией; в папке установки есть `unins000.exe`.
20. Установщик, режим «для всех пользователей»: мастер → «для всех» — запрос UAC; SaySo в `C:\Program Files\SaySo`; ярлык в «Пуск» общий; галочка «Запустить SaySo» запускает SaySo без повышения прав (в Диспетчере задач колонка «Повышенные права» = «Нет»).
21. Обновление поверх (0.1.1 → следующая версия, при запущенном SaySo и открытом окне настроек): запустить новый Setup — мастер предлагает ту же папку и тот же режим; SaySo закрывается сам, без сообщений о занятых файлах; настройки, ключи и история на месте; в «Приложениях» одна запись SaySo с новой версией.
   - Тихое обновление, как делает приложение: `SaySo-Setup-X.Y.Z.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /UPDATE /CURRENTUSER` (или `/ALLUSERS`) — старые процессы SaySo завершены, новый запущен сам, в трее один значок.
   - Тихая установка без `/UPDATE` SaySo не запускает.
22. Удаление с данными: «Приложения» → SaySo → «Удалить» при запущенном SaySo — программа сама закрывает SaySo; на вопрос «Удалить также настройки, ключи и историю» ответить «Да» — исчезли папка установки, ярлык, запись в «Приложениях», значение `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SaySo`, папка `%LOCALAPPDATA%\SaySo`.
23. Удаление без данных: то же, но ответить «Нет» (или нажать Enter — по умолчанию «Нет») — `%LOCALAPPDATA%\SaySo` на месте (`settings.json` не изменился), а после повторной установки ключи и история видны. Тихое удаление (`unins000.exe /VERYSILENT`) тоже оставляет данные.
24. Удаление при включённом режиме администратора: задача Планировщика `SaySo` удаляется только если указывает в удаляемую папку; без прав администратора программа удаления сначала предлагает UAC, а при отказе или неудаче показывает команду `schtasks /Delete /TN SaySo /F`. Задача и Run-значение другой установки не удаляются.
25. Обновление из приложения (нужен опубликованный релиз новее установленной версии, поставленный установщиком): «О программе» → «Проверить обновления» показывает «Доступна версия X.Y.Z» и заметки к релизу, кнопка «Обновить»; в меню трея первым пунктом «Обновить до X.Y.Z», при автоматической проверке всплывает уведомление «Доступна версия X.Y.Z. Нажмите, чтобы обновить». «Обновить» (или щелчок по уведомлению/пункту) скачивает Setup в `%TEMP%\SaySo-Update`, тихо запускает его, SaySo перезапускается новой версией. «Только для меня» — без UAC; «для всех» — UAC запрашивает сам Setup, отказ — «Обновление отменено», SaySo продолжает работать. Закрыть уведомление крестиком — оно о той же версии больше не всплывает, пункт меню и страница «О программе» остаются. Переключатель «Проверять обновления автоматически» в «Общие» выключает автоматическую проверку (после старта и разблокировки в журнале нет обращений к GitHub).
26. Установка «для всех» при SaySo, запущенном в другом сеансе Windows (быстрое переключение пользователей): установщик закрывает SaySo только своего пользователя, чужой остаётся и держит файлы. Файлы не заменяются «после перезагрузки» (флага restartreplace нет): установка завершается ошибкой и откатывается, прежняя версия остаётся. Завершить сеанс другого пользователя (или перезагрузить ПК) и запустить установщик ещё раз — установка проходит.
27. Неудачное обновление: во время тихого `/UPDATE` заблокировать любой файл установки (например, открыть `SaySo.pdb` монопольно) — установка откатывается, а прежний SaySo сам запускается снова, значок в трее на месте.
28. Обновление, которое SaySo не ставит сам: запустить SaySo из ZIP (или после `install.ps1`) либо включить режим администратора, затем «О программе» → «Проверить обновления» при более новом релизе — текст «Доступна версия X.Y.Z. Скачайте установщик со страницы релиза», кнопка «Открыть страницу релиза» и пункт меню «Страница релиза X.Y.Z» открывают страницу релиза; ничего не скачивается и не запускается.
29. Диагностика обновлений на установленной сборке: `SaySo.exe --check-updates --out result.txt` (без демона, окон и трея) — в файле одна строка `current=… outcome=UpToDate|Available|Failed …`, код выхода 0 при состоявшейся проверке; `update-state.json` и `settings.json` не изменились.
30. Плашка поверх окон: открыть окно «всегда поверх» (например, плеер с таким режимом или Диспетчер задач с параметром «Поверх остальных окон»), поместить его над нижней частью экрана, где появляется плашка, и начать диктовку — плашка видна над этим окном, фокус остаётся в прежнем окне; сообщение (например, «Речь не распознана») тоже видно поверх. Меню «Пуск», панель уведомлений и другие системные панели остаются выше плашки: это ограничение обычного приложения (без UIAccess).
31. Нет речи: удерживать правый Ctrl около секунды, ничего не говоря, и отпустить — на плашке «Речь не распознана» (нейтральное сообщение, исчезает через 3 секунды), без звука ошибки, ничего не вставлено, в истории новой записи нет. Короткое нажатие правого Ctrl + C (отмена сочетания) по-прежнему полностью тихое. Если во время записи вынуть USB-микрофон или гарнитуру и ничего не наговорить, на плашке ошибка «Микрофон отключился во время записи» и звук ошибки, а не «Речь не распознана»; если до отключения что-то было сказано, текст вставляется как обычно.
32. Звуковая тема: «Общие» → «Звуки» — в списке 8 тем (Стекло, Капля, Дерево, Колокольчик, Войлок, Подушка, Тап, Калимба), на свежей установке выбран «Войлок». Выбрать каждую тему и нажать «Прослушать» — играет сигнал начала записи этой темы. Выбор сохраняется сразу, перезапуск не нужен: продиктовать фразу — сигнал начала записи и сигнал конца звучат выбранной темой; ошибка (например, неверный ключ без резерва) тоже звучит этой темой. С выключателем «Звуковые сигналы» в положении «Выкл» диктовка тиха, а «Прослушать» всё равно играет.
