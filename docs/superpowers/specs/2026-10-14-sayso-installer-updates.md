# SaySo — установщик и обновления (v0.1.1)

Дополнение к `2026-10-14-sayso-design.md`. Решения владельца (2026-10-14):
- **Установщик:** Inno Setup.
- **Режим установки:** выбирается в мастере — «только для меня» (по умолчанию, без UAC) или «для всех пользователей» (Program Files, с UAC).
- **Выпуск:** v0.1.1, сборка в CI по тегу.
- **Обновления:** проверка и установка в один клик.

## 1. Установщик (`installer/SaySo.iss`)

### Основа
- Inno Setup 6.
- `AppId={{4C827BFC-9A72-4512-910C-1DDC1336642F}` — неизменен во всех версиях, поэтому новый Setup встаёт поверх старого.
- Имя приложения `SaySo`, издатель `Denmurzik`, сайт `https://github.com/Denmurzik/SaySo`, лицензия `LICENSE`.
- Языки мастера: русский (по умолчанию) и английский.

### Права и папка установки
- `PrivilegesRequired=lowest`, `PrivilegesRequiredOverridesAllowed=dialog commandline`. В мастере выбор «для меня / для всех». В командной строке работают `/CURRENTUSER` и `/ALLUSERS`.
- `DefaultDirName={autopf}\SaySo`. Для «только для меня» это `%LOCALAPPDATA%\Programs\SaySo`, для «для всех» — `Program Files\SaySo`.
- `ArchitecturesAllowed=x64compatible`, `ArchitecturesInstallIn64BitMode=x64compatible`, `MinVersion=10.0.19041`.

### Файлы, ярлыки, запуск
- Файлы: всё содержимое AOT-публикации (`artifacts/publish`).
- Ярлык в «Пуске»: `SaySo`. Ярлык на рабочем столе — необязательная задача, по умолчанию выключена.
- После установки в обычном режиме — галочка «Запустить SaySo» (`postinstall nowait skipifsilent`).
- В тихом режиме с ключом `/UPDATE` SaySo перезапускается сам. Запуск от имени исходного пользователя (`runasoriginaluser`), даже если установка шла с повышенными правами.

### Перед установкой (обновление поверх)
- Остановить работающий SaySo текущего пользователя штатно: найти окно класса `SaySo.Daemon.Ipc`, зарегистрировать сообщение `SaySo.Quit` (RegisterWindowMessage) и отправить его через PostMessage.
- Ждать выхода процессов `SaySo.exe` из папки установки до 10 с, затем завершить принудительно.
- Окно настроек закрыть тоже.

### Удаление
- Остановить SaySo, как перед установкой.
- Удалить значение `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SaySo`, если оно указывает в папку установки.
- Удалить задачу Планировщика `SaySo`, если она указывает в папку установки. При установке «только для меня» удалить её можно только с правами администратора: если не удалось, показать подсказку.
- Спросить: «Удалить также настройки, ключи и историю (%LOCALAPPDATA%\SaySo)?» По умолчанию «Нет». В тихом режиме данные не удаляются.

### Сборка и артефакты
- Версия передаётся при сборке: `ISCC /DAppVersion=X.Y.Z /DSourceDir=…`.
- Результат: `artifacts/installer/SaySo-Setup-X.Y.Z.exe` и `artifacts/installer/SaySo-Setup-X.Y.Z.exe.sha256` — одна строка: `<sha256 hex в нижнем регистре>  SaySo-Setup-X.Y.Z.exe`.
- `build-installer.ps1`:
  1. Вызывает `build.ps1`.
  2. Ищет `ISCC.exe` (установленный Inno Setup 6). Если не находит — берёт портативный ISCC из NuGet-пакета `Tools.InnoSetup` в `artifacts/tools`. В системе ничего не устанавливает.
  3. Собирает установщик и пишет `.sha256`.
- Версия X.Y.Z одна на всё: `Directory.Build.props <Version>`.

## 2. Обновления в приложении

### Источник
`GET https://api.github.com/repos/Denmurzik/SaySo/releases/latest`:
- заголовки `User-Agent: SaySo/<версия>` и `Accept: application/vnd.github+json`;
- таймаут 15 с;
- без токена.

Из ответа берутся:
- `tag_name` вида `vX.Y.Z`;
- `html_url`;
- `body` — первые 500 символов как заметки;
- ассеты `SaySo-Setup-X.Y.Z.exe` и `SaySo-Setup-X.Y.Z.exe.sha256` (`browser_download_url`, `size`).

Версии сравниваются по `System.Version` (X.Y.Z). Пре-релизы и черновики не учитываются: их не отдаёт `/latest`.

### Когда проверять — без таймеров в простое
- **Автоматически**, если `AppSettings.CheckForUpdates` = true (по умолчанию true) и с последней проверки прошло ≥ 24 ч. Поводы:
  - через 60 с после старта демона (одноразовый таймер окна);
  - разблокировка сеанса;
  - выход из сна.
- Время последней проверки хранится в `%LOCALAPPDATA%\SaySo\update-state.json` (`lastCheckUtc`, `dismissedVersion`).
- **Вручную** — кнопка «Проверить обновления» на странице «О программе». Окно настроек отправляет демону IPC `SaySo.CheckUpdates`. Если демона нет, проверяет само и показывает результат.
- Ошибки сети молчат (только журнал). Ручная проверка показывает результат: «Установлена последняя версия» или текст ошибки.

### Когда найдена новая версия
- Всплывающее уведомление трея (NIF_INFO): «Доступна версия X.Y.Z — нажмите, чтобы обновить».
- В меню трея появляется пункт «Обновить до X.Y.Z».
- На странице «О программе» — «Доступна версия X.Y.Z» и кнопка «Обновить».
- `dismissedVersion`: если пользователь закрыл уведомление, повторно о той же версии сообщается только в меню и в «О программе», без всплывающего уведомления.

### Установка в один клик
1. Только когда диктовка в состоянии Idle; иначе отложить до конца сессии.
2. Скачать Setup в `%TEMP%\SaySo-Update\`, проверить размер и SHA-256 по `.sha256`. При несовпадении — удалить файл, показать ошибку, ничего не запускать.
3. Определить режим установки:
   - SaySo.exe лежит в `Program Files` → `/ALLUSERS`, запуск через ShellExecute `runas` (UAC);
   - иначе → `/CURRENTUSER`, без повышения.
   - Если SaySo запущен не из установки (рядом нет `unins000.exe`), не ставить, а открыть `html_url` релиза.
4. Запуск: `SaySo-Setup-X.Y.Z.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /UPDATE /CURRENTUSER|/ALLUSERS`. Затем демон штатно завершается (путь Quit). Setup остановит оставшиеся процессы и перезапустит SaySo.
5. Если пользователь отменил UAC — сообщение «Обновление отменено», демон продолжает работу.

### Приватность и безопасность
- В GitHub уходит только запрос о последнем релизе и скачивание файла. Ключи и тексты не отправляются.
- Автоматическую проверку можно выключить на странице «Общие»: «Проверять обновления автоматически».
- Скачанный файл сверяется с SHA-256 из того же релиза. Подписи кода нет: SmartScreen может предупредить при первом запуске Setup. Это описано в README.
- Ничего не логировать, кроме версий и исходов.

## 3. CI — выпуск по тегу (`.github/workflows/release.yml`)
- Триггер: `push` тега `v*.*.*`.
- Проверка: версия из тега должна совпадать с `Directory.Build.props`, иначе ошибка.
- Шаги:
  1. `windows-latest`, setup-dotnet 10;
  2. модульные тесты;
  3. `build-installer.ps1`, нужен MSVC — на раннере есть VS;
  4. создать GitHub Release с ассетами Setup.exe, `.sha256` и ZIP портативной сборки `SaySo-X.Y.Z-win-x64.zip`. Заметки — из `CHANGELOG.md`, секция версии.
- `ci.yml` остаётся для PR и main.
