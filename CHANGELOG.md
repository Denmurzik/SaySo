# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.1] - 2026-10-14

### Добавлено
- Установщик `SaySo-Setup-X.Y.Z.exe` (Inno Setup) в [релизах](https://github.com/Denmurzik/SaySo/releases). Режим выбирается в мастере: «только для меня» (по умолчанию, без прав администратора, `%LOCALAPPDATA%\Programs\SaySo`) или «для всех пользователей» (`Program Files`, запрос UAC). Ярлык в меню «Пуск», необязательный ярлык на рабочем столе, мастер на русском и английском. Тихая установка: `/VERYSILENT /CURRENTUSER` или `/ALLUSERS`.
- Установка поверх прежней версии: работающий SaySo закрывается штатно (через IPC), а если за 10 секунд не вышел — принудительно; настройки, ключи и история сохраняются.
- Удаление через «Параметры → Приложения»: останавливает SaySo, снимает автозапуск (значение Run) и задачу Планировщика, только если они указывают на эту установку, и спрашивает, удалять ли настройки, ключи и историю (по умолчанию нет; при тихом удалении данные остаются).
- Обновление в один клик. SaySo проверяет последний релиз на GitHub не чаще раза в сутки (через минуту после старта, после разблокировки сеанса и после выхода из сна), без таймеров в простое. Новая версия видна во всплывающем уведомлении трея, в пункте меню «Обновить до X.Y.Z» и на странице «О программе», где есть кнопки «Проверить обновления» и «Обновить». Скачанный установщик сверяется с SHA-256 из того же релиза и запускается тихо, SaySo перезапускается сам.
- Настройка «Проверять обновления автоматически» на странице «Общие» (по умолчанию включена). В GitHub уходит только запрос о последнем релизе и скачивание файла, ключи и тексты не отправляются.
- ZIP портативной сборки `SaySo-X.Y.Z-win-x64.zip` в релизе.
- Выпуск по тегу `vX.Y.Z` в GitHub Actions: тесты, сборка установщика и публикация релиза с файлами и заметками из этого журнала.
- Скрипт `build-installer.ps1`: собирает установщик, файл `.sha256` и ZIP; при отсутствии Inno Setup 6 скачивает портативный компилятор в `artifacts/tools`, ничего не устанавливая в систему.

### Изменено
- Лицензия изменена на GPL-3.0-or-later (текст в файле `LICENSE`, его показывает и мастер установки). Версия 0.1.0 остаётся под лицензией Apache-2.0.
- Установщик не подписан цифровой подписью: при первом запуске SmartScreen может показать предупреждение («Подробнее» → «Выполнить в любом случае»).
- `install.ps1` и `uninstall.ps1` остались как способ установки для разработчиков; приложение, поставленное ими, само не обновляется, а открывает страницу релиза.

## [0.1.0] - 2026-10-14

Первый выпуск, лицензия Apache-2.0.

### Добавлено
- Голосовая диктовка для Windows 11: зажмите правый Ctrl, говорите, отпустите — чистый текст вставляется в активное окно любого приложения. Короткое нажатие включает режим «руки свободны», Esc отменяет запись.
- Распознавание Gemini 3.5 Transcribe Live в режиме «Умный»: убирает слова-паразиты, применяет самоисправления, расставляет пунктуацию, заглавные буквы и цифры.
- Несколько ключей Gemini с автоматическим переключением при исчерпании лимита (в том числе посреди фразы, с повторной отправкой записанного) и резерв Groq Whisper с дочисткой текста LLM.
- Вставка через буфер обмена с восстановлением его содержимого; диктовки не попадают в историю Win+V.
- Оверлей с уровнем голоса, состояниями «запись», «обработка», сообщениями об ошибках; значок в трее с меню («Вставить последнее», «Скопировать последнее», «Настройки…», «Приостановить», «Выход»).
- Окно настроек на WinUI 3 (отдельный процесс): «Общие», «Распознавание», «Словарь», «Микрофон», «История», «О программе».
- Словарь терминов, история последних 20 диктовок, выбор микрофона с запоминанием гарнитуры и проверкой уровня.
- Режим администратора: автозапуск задачей Планировщика с наивысшими правами для вставки в окна администратора.
- Лёгкий демон на NativeAOT без XAML: единицы мегабайт в простое.
- Ключи API и история шифруются средствами Windows (DPAPI); аудио на диск не пишется.
- Установка из исходников скриптами `build.ps1` и `install.ps1`.
