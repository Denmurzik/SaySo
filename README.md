# SaySo

> Hold a key. Speak. Get clean text in any Windows app.
> Зажми клавишу. Говори. Получи чистый текст в любом приложении Windows.

**SaySo** is a native Windows 11 voice dictation app (WinUI 3 + .NET NativeAOT) — a lightweight, free alternative to Wispr Flow.
Speech is transcribed by **Gemini 3.5 Transcribe** in *Smart* mode (filler words removed, self-corrections resolved, punctuation added), with **Groq Whisper** as an automatic fallback.

🚧 Work in progress.
