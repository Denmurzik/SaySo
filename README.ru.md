## Почему SaySo

- **Умно, а не дословно.** Речь распознаёт **Gemini 3.5 Transcribe** в режиме *Smart*: убирает «эээ», «ну», «типа», применяет самоисправления («в пятницу, нет, в субботу» → «в субботу»), расставляет пунктуацию, заглавные и цифры.
- **Почти невесомый в фоне.** Демон на NativeAOT вообще не загружает XAML: **6,9 МБ** private-памяти в простое (рабочий набор сжат до 1 МБ). Окно настроек на WinUI 3 — отдельный процесс, который полностью завершается при закрытии.
- **Сказанное не теряется.** Можно добавить несколько ключей Gemini: когда у ключа кончается лимит, SaySo сразу переключается на следующий — даже посреди фразы, дослав уже записанное. Ключи кончились или пропала сеть — запись уходит в **Groq Whisper** с дочисткой текста LLM.
- **Работает везде.** Вставляет текст в активное окно любого приложения; текст в буфере обмена восстанавливается, диктовки не попадают в историю Win+V.
- **Приватно.** Аудио не пишется на диск. Ключи и история зашифрованы средствами Windows (DPAPI). Куда уходят данные: аудио и термины словаря отправляются в Google Gemini; если сработал резерв, аудио, расшифровка и термины словаря уходят в Groq; проверка ключей тоже обращается к этим API. Проверка обновлений обращается к API GitHub (см. [Обновления](#обновления); её можно отключить).

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Удерживать **правый Ctrl** | Идёт запись; отпустили — текст вставлен |
| Коротко нажать **правый Ctrl** | Режим «руки свободны»; повторное нажатие завершает |
| **Esc** во время записи | Отмена, ничего не вставляется |
| Трей → «Вставить последнее» / «Скопировать последнее» | Вернуть последнюю диктовку |

Горячая клавиша, язык, модель, словарь терминов и микрофон настраиваются.

## Скриншоты

### Оверлей и трей

Анимация вверху снята с экрана: это настоящая плашка. Она выезжает из-за нижнего края экрана с лёгкой пружиной: сначала круг, который раздувается в капсулу. Полоски следуют за голосом, во время обработки пульсируют три точки, при смене состояния содержимое плавно сменяется. Материал капсулы — настоящий Acrylic Windows 11 (окна под ней размыты и тонированы), рамка в один пиксель, как у окон Windows 11. На Windows 10, при выключенных «Эффектах прозрачности» и в режиме экономии заряда фон сплошной тёмный, а при выключенных «Эффектах анимации» в Windows плашка просто плавно появляется и исчезает. Текст набран обычным начертанием Segoe UI Variable. Сообщения об ошибке и справочные сообщения — одна короткая строка; полный текст ошибки есть в подсказке значка в трее. Плашка всегда остаётся поверх остальных окон (в том числе других «поверх всех окон») и не забирает фокус; выше неё остаются меню «Пуск» и системные панели, это обычное приложение изменить не может. Если в записи нет речи (тишина, слишком короткая запись или пустой результат), плашка показывает справочное сообщение «Речь не распознана», без звука ошибки; ничего не вставляется и не попадает в историю. Если микрофон отключился посреди записи и ничего записать не удалось, вместо этого показывается ошибка микрофона.

## Установка

Нужно: Windows 11 x64, микрофон, ключ Gemini API (бесплатный тариф) и по желанию ключ Groq (бесплатный) для резерва.

### Установщик (рекомендуется)

1. Скачайте `SaySo-Setup-X.Y.Z.exe` из [последнего релиза](https://github.com/Denmurzik/SaySo/releases/latest) и запустите.
2. Установщик не подписан цифровой подписью, поэтому при первом запуске SmartScreen может показать «Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Чтобы проверить загрузку, сравните `(Get-FileHash .\SaySo-Setup-X.Y.Z.exe).Hash` с содержимым файла `SaySo-Setup-X.Y.Z.exe.sha256` из того же релиза.
3. В мастере выберите режим установки:
   - **Только для меня** (по умолчанию) — права администратора не нужны, SaySo ставится в `%LOCALAPPDATA%\Programs\SaySo`.
   - **Для всех пользователей** — установка в `C:\Program Files\SaySo`, запрос прав администратора (UAC).
4. По желанию добавьте ярлык на рабочий стол и оставьте галочку «Запустить SaySo». Ярлык в меню «Пуск» создаётся всегда. Мастер на русском, а при английском языке интерфейса Windows — на английском.

Установка более нового `SaySo-Setup` поверх старого обновляет программу на месте: работающий SaySo закрывается, настройки, ключи и история сохраняются. Для скриптов: `SaySo-Setup-X.Y.Z.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER` (или `/ALLUSERS`); при тихой установке SaySo не запускается. В режиме «для всех пользователей» установщик закрывает только SaySo того пользователя, который его запустил: копии в других сеансах Windows не останавливаются, и часть файлов может остаться занятой — завершите сеансы этих пользователей (или перезагрузите компьютер) и запустите установщик ещё раз.

**Портативная версия.** В каждом релизе есть `SaySo-X.Y.Z-win-x64.zip`: распакуйте куда угодно и запустите `SaySo.exe`. Копия, поставленная не установщиком, сама обновиться не может: кнопка на странице «О программе» превратится в «Открыть страницу релиза» и откроет страницу релиза.

**Удаление:** «Параметры → Приложения → Установленные приложения → SaySo → Удалить». Программа удаления останавливает SaySo, снимает автозапуск и задачу Планировщика, если они указывают на эту установку, и спрашивает, удалять ли заодно настройки, ключи и историю (`%LOCALAPPDATA%\SaySo`; по умолчанию «Нет», при тихом удалении данные остаются). Задачу Планировщика режима администратора можно удалить только с правами администратора: программа сначала предложит запрос UAC, а если отказаться или не получится — покажет команду `schtasks /Delete /TN SaySo /F`, которую нужно выполнить самому в командной строке от администратора.

### Обновления

SaySo проверяет новые версии в GitHub Releases и может поставить их в один клик.

- **Когда проверяет.** Автоматически, если включено «Общие» → «Проверять обновления автоматически» (по умолчанию включено; в `settings.json` это `checkForUpdates`) и с прошлой проверки прошло не меньше 24 часов (её время и закрытая версия лежат в `%LOCALAPPDATA%\SaySo\update-state.json`). Проверки запускают события: через 60 секунд после старта SaySo, через 15 секунд после разблокировки сеанса и через 15 секунд после выхода компьютера из сна. Таймеров в простое нет; проверка, не состоявшаяся из-за отсутствия сети, повторится на следующем таком событии. Пока идёт диктовка, проверка, загрузка и запуск установщика ждут конца сессии.
- **Ручная проверка.** «О программе» → «Проверить обновления» проверяет сразу и показывает «Установлена последняя версия», либо «Доступна версия X.Y.Z» с заметками к релизу (первые 500 символов), либо причину сбоя (нет связи с GitHub, GitHub не ответил за 15 секунд, лимит запросов).
- **Когда версия найдена.** Всплывающее уведомление в трее «Доступна версия X.Y.Z. Нажмите, чтобы обновить», пункт «Обновить до X.Y.Z» первым в меню трея и кнопка «Обновить» на странице «О программе». Закрытие уведомления и его исчезновение по таймауту считаются отказом: об этой версии оно больше не всплывает, а пункт меню и страница «О программе» остаются. Если уведомление проглотил Windows (помощник по фокусировке, «Не беспокоить»), оно появится снова на следующей суточной проверке.
- **В один клик.** Щёлкните уведомление, пункт меню или кнопку: SaySo скачает `SaySo-Setup-X.Y.Z.exe` в `%TEMP%\SaySo-Update`, сверит размер и SHA-256 с файлом `.sha256` из того же релиза (при несовпадении удалит файл и ничего не запустит), тихо запустит установщик и будет его ждать. Установщик сам закроет SaySo, встанет поверх старой версии и запустит SaySo заново от имени исходного пользователя. Режим — тот, в котором вы устанавливали, его видно по записи об удалении установщика: «только для меня» обновляется без запросов, при «для всех пользователей» установщик сам запросит у Windows права администратора (UAC) — если отказаться, SaySo покажет «Обновление отменено» и продолжит работать. Неудавшееся обновление откатывается, а прежний SaySo запускается снова.
- **Когда SaySo не может поставить сам.** Если SaySo запущен от администратора (режим администратора), копия поставлена не установщиком (ZIP, `install.ps1`) или в релизе нет файлов установщика, ничего не скачивается и не запускается: уведомление гласит «Доступна версия X.Y.Z. Скачайте установщик со страницы релиза», пункт меню превращается в «Страница релиза X.Y.Z», кнопка на странице «О программе» — в «Открыть страницу релиза», и они открывают страницу релиза — новую версию нужно поставить вручную.
- **Что уходит с компьютера.** Один запрос `GET https://api.github.com/repos/Denmurzik/SaySo/releases/latest` (заголовки `User-Agent: SaySo/<версия>` и `Accept: application/vnd.github+json`, токена нет, таймаут 15 с) и скачивание установщика и его `.sha256` с `github.com/Denmurzik/SaySo/releases/…`. Как и при любом веб-запросе, GitHub видит ваш IP-адрес. Ключи, тексты и аудио не отправляются.
- **Диагностика.** `SaySo.exe --check-updates --out result.txt` делает одну проверку без демона, окон и трея и пишет в файл одну строку: `current=0.1.3 outcome=UpToDate`, `outcome=Available latest=X.Y.Z installable=True|False …` или `outcome=Failed failure=Network|Timeout|RateLimited|BadResponse`. Код выхода: 0 — проверка состоялась, 2 — сбой проверки, 3 — непредвиденная ошибка. `--out` нужен, потому что у `SaySo.exe` нет окна консоли. Команда не меняет `update-state.json` и `settings.json`.

### Сборка из исходников

Для разработки: нужны .NET 10 SDK и Visual Studio Build Tools с компонентом C++ для NativeAOT.

```powershell
git clone https://github.com/Denmurzik/SaySo
cd SaySo
powershell -ExecutionPolicy Bypass -File .\build.ps1             # NativeAOT-публикация в artifacts/publish; нужно >= 4 ГБ свободной ОЗУ
powershell -ExecutionPolicy Bypass -File .\install.ps1           # копирует в %LOCALAPPDATA%\Programs\SaySo, ярлык в «Пуск», запуск
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1   # собирает artifacts/installer/SaySo-Setup-X.Y.Z.exe (+ .sha256) и портативный ZIP
```

Удаление копии, поставленной `install.ps1`: `powershell -ExecutionPolicy Bypass -File .\uninstall.ps1` (с `-RemoveData` — вместе с настройками, ключами и историей). Оба скрипта принимают `-Target <папка>` и `-WhatIf`. `build-installer.ps1` использует установленный Inno Setup 6.3+, если найдёт его; иначе скачивает портативный компилятор (пакет NuGet `Tools.InnoSetup`) в `artifacts/tools` и ничего не ставит в систему. Релизы собирает GitHub Actions при пуше тега `vX.Y.Z` (тег должен совпадать с `<Version>` в `Directory.Build.props`).

Для разработки и снимков экрана: переменная окружения `SAYSO_DATA_DIR` (абсолютный путь, относительный игнорируется) заставляет SaySo хранить настройки, ключи, историю и журнал в этом каталоге вместо `%LOCALAPPDATA%\SaySo`, и настоящие данные остаются нетронутыми.

## macOS

SaySo работает и на macOS 12 Monterey и новее, на Mac с Apple Silicon и Intel. Это то же приложение: общее ядро (Gemini Live с переключением ключей, резерв Groq, сценарий диктовки, настройки, история, проверка обновлений) — тот же код, что у версии для Windows, а родной для macOS только платформенный слой: значок в строке меню вместо трея, горячая клавиша через перехват событий Quartz, запись через Core Audio, вставка через буфер обмена и Cmd+V, плашка на Core Animation с настоящим размытием подложки (`NSVisualEffectView`). Интерфейс, как и в Windows, на русском.

### Установка на macOS

1. Скачайте `SaySo-X.Y.Z-macos.dmg` из [последнего релиза](https://github.com/Denmurzik/SaySo/releases/latest) (одно универсальное приложение для Apple Silicon и Intel), откройте его и перетащите `SaySo.app` на «Программы». Рядом лежит и `SaySo-X.Y.Z-macos.zip` с тем же приложением. Проверить файл: `shasum -a 256 SaySo-X.Y.Z-macos.dmg` и сравнить с `SaySo-X.Y.Z-macos.dmg.sha256`.
2. Приложение не нотаризовано Apple (подпись ad hoc), поэтому первый запуск блокирует Gatekeeper. Щёлкните `SaySo.app` правой кнопкой → «Открыть» → «Открыть» или запустите его один раз и нажмите «Всё равно открыть» в «Системные настройки → Конфиденциальность и безопасность». Из Терминала: `xattr -dr com.apple.quarantine /Applications/SaySo.app`.
3. SaySo появится микрофоном в строке меню (значка в Dock нет) и при первом запуске откроет окно настроек. Дайте два разрешения, когда macOS их попросит (страница «Общие» показывает их состояние, а кнопки открывают нужный раздел Системных настроек):
   - **Универсальный доступ**: без него SaySo не видит горячую клавишу и не может вставить текст через Cmd+V. Пока его нет, в меню значка есть пункт «Разрешить Универсальный доступ…»; горячая клавиша заработает в течение двух секунд после разрешения, без перезапуска.
   - **Микрофон**: спрашивается при первом запуске.

| Действие | macOS |
|---|---|
| Удерживать **правый ⌘ (Cmd)** | Запись, пока клавиша зажата; при отпускании текст вставляется |
| Коротко нажать **правый ⌘** | Режим «руки свободны»; повторное нажатие завершает |
| **Esc** во время записи | Отмена, ничего не вставляется |

На клавиатурах MacBook нет правого Control, поэтому на macOS по умолчанию — правый Cmd. На странице «Общие» можно записать любое сочетание, в том числе одну клавишу **Fn (🌐)**; Caps Lock на macOS горячей клавишей быть не может: macOS сообщает только о переключении его состояния. Пока в macOS включён «защищённый ввод» (фокус в поле пароля или в Терминале включён «Безопасный ввод с клавиатуры»), горячая клавиша не видна: это защита macOS, её не обходит ни одно приложение.

Где что лежит на macOS:

- **Настройки, история, ключи, журнал:** `~/Library/Application Support/SaySo` (`SAYSO_DATA_DIR` работает так же). Ключи API и история зашифрованы AES-256-GCM, ключ шифрования хранится в Связке ключей пользователя (запись «SaySo»). Связка ключей пускает к записи только создавшую её программу, поэтому после замены `SaySo.app` новой версией macOS может один раз спросить, можно ли SaySo её использовать: выберите «Разрешать всегда».
- **Вставка:** продиктованный текст кладётся в буфер обмена с пометкой «временный» (`org.nspasteboard.TransientType`), поэтому менеджеры буфера его не запоминают, а затем в буфер возвращается всё, что в нём было (текст, картинки, файлы). «Вставить последнее» и «Скопировать последнее» — в меню значка.
- **Автозапуск:** «Общие → Открывать при входе в систему» создаёт `~/Library/LaunchAgents/io.github.denmurzik.sayso.plist`, который запускает приложение через `open -g -a`.
- **Плашка:** видна поверх полноэкранных приложений и на всех рабочих столах, фокус не берёт и пропускает щелчки. При «Уменьшить прозрачность» фон сплошной, при «Уменьшить движение» плашка просто проявляется и гаснет.
- **Обновления:** проверяются так же и по тем же событиям, что в Windows (старт, выход из сна, разблокировка), но установщика нет: о новой версии один раз сообщает плашка, а пункт меню «Страница релиза X.Y.Z» открывает страницу релиза, откуда скачивается новый zip.
- **Режим администратора** есть только в Windows: macOS для вставки повышение прав не нужно.

**Удаление:** «Выйти из SaySo» в меню значка, затем удалите `SaySo.app`, `~/Library/LaunchAgents/io.github.denmurzik.sayso.plist` и, если нужно стереть настройки, ключи и историю, `~/Library/Application Support/SaySo` и запись «SaySo» в Связке ключей (программа «Связка ключей»).

**Сборка из исходников на Mac:** .NET SDK из `global.json` и Xcode Command Line Tools (`xcode-select --install`; сам Xcode не нужен).

```bash
./build-macos.sh                 # NativeAOT для arm64 и x86-64 → artifacts/macos/SaySo.app и artifacts/release/SaySo-X.Y.Z-macos.zip и .dmg
./build-macos.sh --arch arm64    # только Apple Silicon, быстрее
open artifacts/macos/SaySo.app
dotnet test --project tests/SaySo.Core.Tests --filter-not-trait "Category=Integration"   # на macOS: общее ядро и macOS-ветви
```

Диагностика на macOS та же, что в Windows: `SaySo.app/Contents/MacOS/SaySo --check-updates`, `--overlay-demo --out result.txt` (пишет физическую память процесса вместо private-байт) и `--simulate файл.wav [--insert]`.

## Настройки

Открываются из значка в трее (двойной клик или правая кнопка → «Настройки…»). Окно называется «SaySo», боковое меню в нём всегда раскрыто: «Общие», «Распознавание», «Словарь», «Микрофон», «История», «О программе». Это отдельный процесс: закрыли окно — процесс завершился. Значок можно скрыть («Общие → Значок в трее»); тогда настройки открываются повторным запуском SaySo из меню «Пуск». Там же, на странице «Общие», настраивается прозрачность плашки.

### Звуки

SaySo коротко сигналит в начале записи, в её конце и при ошибке. «Общие → Звуки» предлагает восемь тем: «Стекло», «Капля», «Дерево», «Колокольчик», «Войлок» (по умолчанию), «Подушка», «Тап» и «Калимба». Кнопка «Прослушать» играет сигнал начала записи выбранной темы. Выбор сохраняется сразу и действует на запущенный SaySo без перезапуска; выключатель «Звуковые сигналы» отключает все сигналы. Звуки встроены в `SaySo.exe` (около 2 МБ) и создаются скриптом `tools/sounds/generate_sounds.py`. Они читаются прямо из SaySo.exe, лишней приватной памяти нет.

### Микрофон

SaySo запоминает выбранный микрофон. Выбранная гарнитура подхватывается автоматически, как только её подключили снова: ищется по идентификатору устройства, а если Windows выдала новый идентификатор (гарнитуру воткнули в другой USB-порт) — по имени. Пока гарнитура отключена, диктовка идёт через микрофон Windows по умолчанию. Явно выбранный встроенный микрофон остаётся выбранным, даже если подключена гарнитура. Пункт «Как в Windows (по умолчанию)» всегда следует за устройством по умолчанию в Windows. «Проверить микрофон» показывает живую полоску уровня.

<p align="center"><img src="docs/assets/settings-microphone.png" width="560" alt="Настройки: Микрофон"></p>

### Режим администратора (по желанию)

Обычное приложение не может вставлять текст в окна, запущенные от администратора (терминалы с повышенными правами, некоторые IDE): SaySo оставляет текст в буфере обмена и сообщает об этом на плашке. «Общие → Запускать от имени администратора» снимает это ограничение: SaySo запускается при входе в систему задачей Планировщика с наивысшими правами (при включении один раз появится запрос UAC). Режим администратора запускает `SaySo.exe` с повышенными правами из папки установки, в которую могут писать программы вашей учётной записи, — включайте его, только если доверяете программам на этом компьютере (то же предупреждение показано у переключателя).

## Память

Замеры на Windows 11 (x64), сборка Release NativeAOT. Строки таблицы измерены на 0.1.2; плашка 0.1.3 измерена отдельно, под таблицей:

| Процесс | Private | Рабочий набор |
|---|---|---|
| Демон в простое после старта | 6,9 МБ | 0,2 МБ |
| Демон через 10 с после записи 1,5 с (ключи-заглушки, без завершённого распознавания) | 8,8 МБ | 0,3 МБ |
| Окно настроек открыто (через 6 с после запуска) | 93,4 МБ | 147,5 МБ |
| Окно настроек закрыто | процесса нет | процесса нет |

Размер публикации: 69,2 МБ (`SaySo.exe` — 12,2 МБ, из них около 2 МБ встроенные звуки). Все размеры здесь в мебибайтах (1 МБ = 1 048 576 байт), как их печатают `build.ps1` и скрипты измерения.

Демон сжимает рабочий набор после старта и после каждой сессии, поэтому его рабочий набор остаётся меньше 1 МБ, а показательнее столбец Private; окно настроек не сжимается. Строка про диктовку измерена без завершённого распознавания: реальная диктовка добавляет сетевые буферы (WebSocket/TLS/HTTP), так что ожидайте несколько больше.

Плашка существует, только пока она на экране: компоновщик, визуалы и очередь сообщений создаются при появлении и освобождаются после того, как она уехала; таймеров не остаётся. `SaySo.exe --overlay-demo --out result.txt [--cycles N]` прогоняет плашку через все состояния тем же кодом, что у демона (без горячей клавиши, трея и мьютекса единственного экземпляра, поэтому запускается рядом с работающим SaySo), и пишет в файл private-память этого процесса (не демона: у демона в простое 6,9 МБ): 6,6 МБ до первого показа, 7,3–7,8 МБ, пока плашка видна, 7,4 МБ после скрытия и сброса памяти и столько же после каждой следующей сессии (около +0,8 МБ один раз; замер на 3 сессиях).

## Сборка и тесты

```powershell
dotnet test --project tests/SaySo.Core.Tests --filter-not-trait "Category=Integration"   # модульные
dotnet test --project tests/SaySo.Core.Tests --filter-trait "Category=Integration"       # микрофон, буфер, хук

dotnet run --project tools/SaySo.Probe -- overlay-capture --exe artifacts/publish/SaySo.exe --out-dir docs/assets   # запись плашки для README
```
